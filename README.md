## `whoami`

I'm **Nicat Sultanov ([@Sultan0f1](https://github.com/Sultan0f1))**, a third-year Computer Engineering student at **Baku Engineering University**, focused on offensive security.

I work on web application security, Active Directory attack paths, Linux and networking while training in Red Team Security at **Millisec**. I also research vulnerabilities in open-source software and practice responsible disclosure through GitHub Security Advisories and bug bounty platforms.

My goal is straightforward: understand systems deeply, validate findings carefully, and document every result with evidence that can be reproduced.

> *Break with purpose. Report with proof. Learn from every system.*

---

## Focus

- **Web Application & API Security** — authorization, business logic and server-side vulnerability testing.
- **Vulnerability Research** — source-code review, reproducible PoCs, CVSS/CWE mapping and responsible disclosure.
- **Active Directory & Red Teaming** — enumeration, Kerberos/NTLM fundamentals and attack-path analysis.
- **Security Automation** — evidence-first recon, deterministic validation and structured reporting.

## Featured project

### Pentest Workbench

> A private, actively developed agent-driven penetration-testing workspace for repeatable security research.

It combines recon, vulnerability hunting, deterministic validation, evidence collection, duplicate checks and report generation into one workflow. The project is designed around a simple rule: **a finding is not ready until it is reproducible and supported by clean evidence**.

`Python` `Bash` `Recon` `Validation` `Reporting` `Security Automation`
